# Материалы для переноса в Figma

Это снимки реально работающего приложения и описание макета. Редактируемый Figma-файл создан по этим материалам: [Столик — курсовой проект Майорова](https://www.figma.com/design/Ho8a3G7m2Z1rZoEryM5ppp). Снимки в этой папке остаются материалами для визуальной сверки.

Экраны: каталог, выбор двух столиков, успешное сохранение, список бронирований, подтверждение отмены, ресторан с занятыми столиками; каталог и форма при ширине 390 px. Контакты и брони вымышленные, сняты в изолированном браузерном контексте.

Воспроизведение: запустить `npm.cmd start`, затем `node scripts/export-design.cjs` в другом терминале.

## Структура макета

- Страница «Компоненты»: кнопка, поле ввода, карточка ресторана, столик, уведомление, навигация. Состояния: обычное, фокус, недоступно, выбрано, ошибка.
- Страница «Desktop»: фреймы шириной 1440 px по снимкам 01–06.
- Страница «Mobile»: фреймы шириной 390 px по снимкам 07–08.
- Прототип: каталог → выбор столиков → подтверждение → мои бронирования → подтверждение отмены.

Основные цвета из CSS: фон #F7F6F0, текст #213C32, кнопки #254F3D, панели #FFFFFF, мягкий фон #E9EDE2, фокус #B87925, ошибка #923E24. Шрифты: Arial для интерфейса, Georgia для крупных заголовков. Радиусы: 7–8 px для полей и кнопок, 12 px для карточек, 15 px для диалога. Основной контейнер: максимум 1200 px; контрольные точки адаптивности: 800 и 520 px.

Названия компонентов связаны с БЭМ-блоками кода: button, field, restaurant-card, table-map, notice, header. В курсовую добавлены ссылка на файл, снимок макета главного экрана и описание реально созданного прототипа.
